# LightForge Marketing

Independent Nuxt 3 marketing site for LightForge.

```bash
# from repo root
pnpm install
pnpm dev:marketing
```

Open http://localhost:3001

Login CTA targets `NUXT_PUBLIC_APP_URL` (default https://app.lightforgecrm.com).

Production marketing domain: **https://www.lightforgecrm.com**

See `docs/marketing/marketing-architecture.md`.
